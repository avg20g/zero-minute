Zero Minute: 3D model reference board

60 reference photos and drawings of real equipment, matched to units in the game. Pictures load from Wikimedia Commons, so this page needs an internet connection. Click a picture for the full-size original and its licence. To keep copies in this folder, run download-photos.command (double-click it on a Mac).
